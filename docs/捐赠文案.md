# 开发者互助基金 · 捐赠文案

> 用途：成功项目的 DEV 自愿捐赠，供养后续创业者（代付 FLAP 创建费）。
> 基调：不卖惨、不道德绑架，强调「接力」与「自愿」。零强制、零抽成、链上公开。

## 一、捐赠区（网站内嵌卡片）

**标题**：开发者互助基金

**徽标**：自愿 · 公开 · 零强制

**引导语**：
每一位成功上线的 DEV，都可以自愿留下一份发射成本，让下一位创业者继续零成本出发。

**主标语**：
今天你被扶持，明天你扶持别人。

**说明**：
捐款直接进入发射金库，用于代付后续创业者的 FLAP 创建费。全部链上公开可查，不强制、不抽成、不设最低门槛。

**按钮**：捐款支持（转账中：转账中…）

**感谢语**：
感谢你的捐赠。下一枚 0 手续费代币背后，有你的一份燃料。

**失败兜底**：
交易未完成（可能被钱包拒绝）。捐赠纯属自愿，随时可以再来。

**未连接钱包提示**：
请先连接钱包。捐款是自愿的：成功后回馈一次发射成本，帮下一位创业者零成本出发。

## 二、发射成功后引导（成功卡片尾部）

项目起飞后，欢迎向开发者互助基金捐赠一次发射成本，让下一位 DEV 零成本出发。

## 三、白皮书/文档用段落

发射费用由谁承担？由每一位愿意回馈的 DEV。Vortex 不设置任何强制偿还机制——
成功的项目自愿捐赠一次发射成本，汇入开发者互助基金，代付后来者的创建费。
这笔钱链上公开，流向清晰：从成功者手中，到下一位创业者手中。

## 五、合规提示

- 全程使用「捐赠 / 自愿 / 互助」措辞，不承诺任何回报、空投或分红；
- 不设排行榜、不设最低门槛、不对未捐赠者做任何区别对待；
- 基金地址与支出建议通过多签管理，链上可查。

## 六、荣誉墙（Honor Wall）

**区块标题**：荣誉墙

**副标语**：每一位捐赠者，都会被记录在这里。链上核验，公开可见。

**表单**：
- 项目名称（荣誉墙展示）— 占位符：你的代币或项目名，如：币安公主
- 项目 LOGO（选填，不上传则用首字母头像）

**上榜提示**：交易经链上核验后自动上榜，所有人可见。

**FAQ 条目**：
- 怎么上荣誉墙？ 捐款时填写项目名称与 Logo，交易经链上核验后自动上榜，所有人可见。
