## 1. 摘要

Vortex 是 FLAP 的手续费代付网关。创作者在 Vortex 填写表单（名称、符号、描述、Logo 与发射参数），由 Vortex 热钱包代付 FLAP 创建手续费（约 0.001 BNB）并调用 FLAP Portal 合约完成上链——代币最终上线 FLAP 平台交易，创作者全程 0 手续费、0 Gas、无需前置打款。

Vortex 的经济模型建立在**双闭环费用引擎**之上：

- **第一闭环 · 代付兜底**：Vortex 中继器热钱包代付每一次 FLAP 创建费与上链 Gas，用户零成本发币；发射完成即闭环，代币交易与费收归 FLAP 协议运行。
- **第二闭环 · 平台燃料**：Vortex 发行平台代币 **VX**。**VX 交易产生的税费统一注入发射金库（Launch Treasury），作为承担发射台上所有代币发射费用的资金来源**——包括中继器 Gas 垫付、无人交易代币的沉没成本兜底、以及生态激励。

一句话概括：**平台代币的税费，就是发射台运转的燃料。** 发射越多，平台代币的交易规模越大，金库越雄厚，发射成本越低，最终让每一枚新代币都能「零税率、零手续费」出生。

## 2. 背景与痛点

在 BSC 上从零创建一枚代币并开池，通常需要：

1. **Gas 门槛**：部署合约、创建底池、管理流动性都需要持有 BNB 并支付 Gas，新用户往往被挡在门外；
2. **前置收费**：传统发射台收取固定创建费（0.1–1 BNB 不等），代币尚未交易、项目尚未验证，费用已先发生；
3. **沉没成本**：若代币上线后无人交易，创建者损失全部创建费用，发射失败的成本完全由个人承担；
4. **狙击风险**：开盘瞬间的机器人抢跑（挖、提、卖）损害早期参与者利益；
5. **流动性冷启动**：新代币无底池、无深度，开盘即死。

Vortex 的对策：

| 痛点 | Vortex 方案 |
| --- | --- |
| Gas 门槛 | EIP-712 签名发射，Gas 由中继器代付，创作者 0 Gas |
| 前置收费 | 费用后置：从代币交易中回收，发射前不收取任何费用 |
| 沉没成本 | 发射金库兜底；无人交易时代币成本由平台吸收，创作者零损失 |
| 狙击风险 | 防「挖、提、卖」保护期，开盘窗口内禁止卖出 |
| 流动性冷启动 | 内置联合曲线，虚拟储备开盘，无需初始流动性资金 |

## 4. 代付引擎：0 手续费上链

一次完整发射的流程：

```
创作者填写表单（名称/符号/描述/Logo/发射模式/税率/分配/保护期）
        │
        ▼
Cloudflare Turnstile 人机验证（防脚本刷单）
        │
        ▼
Vortex 中继器校验：Turnstile → 速率限制（IP 10 分钟 1 次 / 钱包每日 3 次）
        │
        ▼
热钱包代付创建费（约 0.001 BNB），磨盐命中地址后缀（7777/8888）
        │
        ▼
调用 FLAP Portal newTokenV6() 上链
        │
        ▼
代币上线 FLAP：https://flap.sh/bnb/{token}
```

**风控体系**：

- Turnstile 人机验证，阻断脚本批量发币；
- 同一 IP 每 10 分钟限发 1 次，同一钱包每日上限 3 次；
- 中继器热钱包资金隔离与限额，私钥托管于密钥管理服务（KMS）；
- 保留 CA（lockSalt）模式下，盐与代币版本不一致将被 Portal 合约拒绝。

## 5. 发射模式

Vortex 支持四种可执行的发射模式（`launchMode` 0–3），覆盖不同项目需求：

| 模式 | FLAP 对应 | 说明 |
| --- | --- | --- |
| 税收模式 | TOKEN_TAXED_V3 | 买/卖税率 0–10%，税收分配：创作者钱包/销毁/分红/流动性（合计 100%） |
| 零税标准代币 | TOKEN_V2_PERMIT | 无买卖税，联合曲线阶段后迁移 DEX |
| 保留 CA | lockSalt | FLAP 盐锁定：提前锁定可预测合约地址（7777/8888 后缀），预热后发布 |
| 股票计价池 | 股票代币 | 90+ 股票代币计价池（NVDAB/QQQB/XAUT 等） |

**附加可选配置**：

- **买/卖税率**：0–10% 滑块，仅在税收模式下生效；
- **防「挖、提、卖」保护期**：关闭 / 5 / 15 / 30 分钟（合约上限 30 天），期间禁止卖出，防开盘狙击；
- **保留 CA 预发射**：通过 FLAP `lockSalt` 提前锁定可预测的合约地址（7777/8888 后缀），社群预热后择时发布；
- **支付代币**：当前支持 BNB 计价；**90+ 股票代币计价池**（英伟达 NVDAB、台积电 TSMB、特斯拉 TSLAB、标普 500 SPYB、纳斯达克 100 QQQB、SpaceX SPCXB、小米/腾讯/泡泡玛特封装股、半导体 3 倍杠杆 ETF 等）已接入选择器，链上化随路线图推进。

## 6. 费用闭环（核心经济模型）

### 6.1 第一闭环：代付兜底

Vortex 热钱包代付每一次 FLAP 发射成本，用户全程零支出：

```
用户提交表单（0 手续费）
      │
      ▼
Vortex 热钱包代付 FLAP 创建费（约 0.001 BNB）+ 上链 Gas
      │
      ▼
FLAP Portal newTokenV6() 发射代币
      │
      ▼
代币上线 FLAP 交易（曲线阶段平台费 1% 归 FLAP 协议）
```

- 发射成功：用户零成本获得一枚上线 FLAP 的代币；
- 发射失败（合约回滚）：创建费损失由 Vortex 承担——**由第二闭环的发射金库兜底**，创作者依旧零损失。

### 6.2 第二闭环：平台代币燃料（本白皮书核心）

Vortex 发行平台代币 **VX**，将其交易税费转化为发射台的公共燃料。

**VX 税费的用途（发射金库 Launch Treasury）**：

1. **代付全平台 FLAP 发射费用**：持续补充中继器热钱包，让所有代币在 FLAP 上的创建费与上链 Gas 由金库承担；
2. **沉没成本兜底**：覆盖发射失败与「无人交易代币」的垫付损失，保证「0 手续费、失败零成本」的承诺始终成立；
3. **生态激励**：优质项目税费返还、创作者补贴、安全审计预算；
4. **金库升级路径**：当金库储备充足，可支撑更高频的零成本代付与面向优质创作者的手续费返还——代付网关进入完全免费时代。

**资金流全景**：

```
            ┌──────────────────────────────┐
  交易 VX ──▶│  VX 买卖税费  ──────▶ 发射金库 │──▶ 代付 FLAP 创建费 / 兜底 / 激励
            └──────────────────────────────┘
                          │ 代付创建费 + Gas
                          ▼
            ┌──────────────────────────────┐
  用户填表 ──▶│  中继器（热钱包）──▶ FLAP Portal │
            └──────────────────────────────┘
                          ▲
          代币上线 FLAP 交易（第一闭环）────┘
```

**飞轮效应**：发射台交易量增长 → VX 交易活跃 → 税费流入金库 → 金库更强 → 可支持更多「零税发射」→ 吸引更多创作者与交易者 → 交易量再增长。发射费用从「每个项目自己掏」变成「全平台共同供养」，成本随规模递减直至趋近于零。

**分配方案**：

| 用途 | 比例 | 说明 |
| --- | --- | --- |
| 发射金库 | 40% | 垫付与兜底全平台发射费用，多签管理 |
| 初始流动性 | 20% | 建立 VX/BNB 交易对 |
| 生态激励 | 15% | 创作者补贴、优质项目返还、活动奖励 |
| 团队 | 15% | 线性解锁，长期绑定 |
| 社区空投 | 10% | 早期创作者与交易者激励 |

**交易税费（建议值，部署前可调）**：

| 环节 | 税率 | 去向 |
| --- | --- | --- |
| 买入 | 3% | 2% 发射金库 · 0.5% 销毁 · 0.5% 流动性 |
| 卖出 | 3% | 2% 发射金库 · 0.5% 销毁 · 0.5% 流动性 |

**VX 价值逻辑**：

- 持续销毁通缩，供应量随平台交易规模收缩；
- 发射金库余额链上可查，燃料规模透明公开；
- 金库规模扩大直接转化为更低发射成本与更多免费发射，吸引交易量回流 VX；
- 后续版本 VX 可用于发射费用减免、保留 CA 优先权与协议治理投票。
